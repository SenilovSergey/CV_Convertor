# Локальный конвертер резюме QA с ChatGPT Work

Приложение переносит резюме из DOCX, DOC, RTF или PDF в корпоративный шаблон. После проверки можно скачать DOCX или PDF. Для помощи с черновиком предусмотрен обмен текстом с ChatGPT Work. Приложение открывается на вашем компьютере и работает без API-ключа.

## Запуск в Windows

1. [Скачайте ZIP](https://github.com/SenilovSergey/CV_Convertor/archive/refs/heads/local-web-work.zip) и распакуйте весь архив.
2. Дважды щёлкните по файлу `Start-CV-Convertor.cmd` в распакованной папке. Понадобится установленный Node.js 22 или новее.
3. Браузер откроет конвертер. Если вкладка не появилась, откройте адрес из окна запуска. По умолчанию это [http://127.0.0.1:8789/](http://127.0.0.1:8789/). Оставьте окно запуска открытым, пока работаете с резюме.

Альтернативный запуск из папки приложения в терминале:

```console
node server.mjs
```

## Работа с резюме

1. Загрузите файл и выберите полную или сокращённую шапку. В полной версии можно проверить или изменить ФИО, телефон, email и фото кандидата.
2. Сверьте поля локального редактора с исходным файлом. При необходимости добавьте описание вакансии.
3. Чтобы получить черновик от ChatGPT, нажмите **«Подготовить запрос»**. Проверьте текст, затем нажмите **«Скопировать запрос»**. Конвертер скрывает распознанные контакты. Оставшиеся личные и конфиденциальные сведения можно удалить из запроса перед копированием.
4. Откройте ChatGPT, выберите **Work** и вставьте запрос в сообщение. Скопируйте ответ, вернитесь в конвертер, нажмите **«Вставить ответ ChatGPT»** и вставьте ответ. Сравните черновик с полями редактора и нажмите **«Применить черновик»**, чтобы перенести предложенный текст.
5. При необходимости поправьте поля и нажмите **«Сформировать .DOCX»** или **«Сформировать .PDF»**. В сокращённой версии документ использует «Имя Ф.» и не включает контактные поля и фото из шапки.

Файл, фото и поля шапки обрабатываются в браузере. В ChatGPT Work попадает текст, который вы сами вставляете в сообщение. Если вы хотите обработать резюме в самом конвертере, пропустите шаги 3 и 4.

Сканы без текстового слоя и документы с паролем требуют текстовой копии.

## Проверка

`node --test` проверяет маршруты локального сервера, подготовку запроса и импорт ответа. Эта версия поддерживается отдельно от [первоначального веб-конвертера](https://senilovsergey.github.io/CV_Convertor/).
