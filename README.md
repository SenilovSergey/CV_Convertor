# Конвертер резюме QA

Веб-приложение переносит резюме кандидата (.docx, .doc, .rtf или .pdf) в корпоративный шаблон и выдаёт готовый файл .docx или .pdf. Если вставить требования вакансии, Claude расставит в резюме акценты под неё, не добавляя опыта, которого в резюме нет.

Всё работает в браузере: у сайта нет сервера. Текст резюме уходит только в API Anthropic по ключу того, кто пользуется страницей.

## Как пользоваться

1. Откройте сайт и в блоке «Подключение к Claude» вставьте ключ API Anthropic. Создать ключ можно в Claude Console: console.anthropic.com → API Keys. Запросы оплачиваются с баланса этого ключа.
2. Загрузите резюме, выберите вид шапки (полная или «Имя Ф.»), при необходимости поправьте ФИО, контакты и фото.
3. Если нужно, вставьте требования вакансии.
4. Нажмите «Сформировать .DOCX» или «Сформировать .PDF».

Имя файла: фамилия кандидата для полной шапки, «Имя Ф.» для сокращённой.

## Публикация на GitHub Pages

1. Загрузите в корень репозитория все файлы из архива: `index.html`, `template.b64.txt`, `README.md` и папку `lib`.
2. Откройте Settings → Pages. В Source выберите Deploy from a branch, ветку `main`, папку `/ (root)`, затем Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<имя-репозитория>/` (для этого репозитория: https://senilovsergey.github.io/CV_Convertor/).

Чтобы обновить сайт, загрузите новые версии файлов тем же способом: Add file → Upload files.

## Состав

- `index.html`: приложение, вся разметка, стили и логика в одном файле.
- `template.b64.txt`: корпоративный шаблон резюме (.docx в кодировке base64), из него берутся оформление, шрифты Montserrat и логотипы.
- `lib/jszip.min.js`: работа с .docx (JSZip).
- `lib/pdf.min.mjs`, `lib/pdf.worker.min.mjs`: чтение PDF (pdf.js).

## Ограничения

- Не читаются сканы без текстового слоя, файлы Word 6/95 и файлы с паролем.
- PDF рисуется отдельно по тому же макету, что и .docx. Ручные правки .docx в Word в него не попадают.
- API Anthropic доступен не во всех странах; ключ должен принадлежать организации в поддерживаемом регионе.
