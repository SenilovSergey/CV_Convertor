# Конвертер резюме QA с ИИ

Веб-приложение переносит резюме кандидата (.docx, .doc, .rtf или .pdf) в корпоративный шаблон и выдаёт готовый файл .docx или .pdf.

Эта версия запускается отдельно в ветке `ai-version`. [Опубликованный конвертер](https://senilovsergey.github.io/CV_Convertor/) работает из ветки `main`.

## Локальный запуск

Установите Node.js 22 или новее. В PowerShell выполните:

```powershell
git clone --branch ai-version https://github.com/SenilovSergey/CV_Convertor.git CV_Convertor_AI
cd CV_Convertor_AI
$key = Read-Host 'Ключ OpenAI API' -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $key).Password
Remove-Variable key
node server.mjs
```

Откройте [http://127.0.0.1:8788/](http://127.0.0.1:8788/). Сервер принимает подключения с этого компьютера. Для ИИ нужен [ключ OpenAI API](https://platform.openai.com/api-keys) с доступом к модели. По умолчанию используется `gpt-4.1-mini`, модель можно задать через `OPENAI_MODEL`. Чтобы запустить редактор и экспорт без ИИ, пропустите ввод ключа.

## Как пользоваться

1. Загрузите резюме. Оно сразу разбирается по правилам: ФИО и контакты, должность, стаж, места работы (период, компания и проект, должность, обязанности, достижения, стек), навыки, образование, курсы, языки.
2. Выберите вид шапки (полная или «Имя Ф.»), при необходимости поправьте ФИО, контакты и фото.
3. При необходимости вставьте описание вакансии. Кнопка «Применить к резюме» поднимает совпадающие пункты по локальным правилам. ИИ тоже может учесть вакансию при подготовке черновика.
4. Для помощи ИИ нажмите «Подготовить черновик». Проверьте или отредактируйте текст резюме и вакансии в окне отправки. После ответа откройте «Посмотреть черновик» и сравните его с текущим редактором. Чтобы принять предложенные формулировки, нажмите «Применить черновик».
5. Проверьте и исправьте поля в блоке «Проверка и правка», затем сформируйте DOCX или PDF.

Имя файла: фамилия кандидата для полной шапки, «Имя Ф.» для сокращённой.

Разбор лучше всего работает с выгрузками hh.ru, Хабр Карьеры и внутренними резюме ЛАНИТ; резюме свободной формы может потребовать больше ручных правок.

## Передача данных

Файл, фото и поля шапки обрабатываются в браузере. По кнопке «Отправить в OpenAI» локальный сервер передаёт текст из окна подтверждения в OpenAI API. Приложение скрывает распознанные ФИО и контакты. Проверьте оставшийся текст резюме и вакансии перед отправкой. Ключ доступен только локальному серверу. В запросе передаётся `store: false`. Подробнее об обработке данных см. [документацию OpenAI API](https://developers.openai.com/api/docs/guides/your-data).

## Состав

- `index.html`: приложение (разметка, стили, разбор резюме, редактор, сборка .docx и .pdf) в одном файле.
- `resume-ai.js`: проверка отправляемого текста и сравнение черновика с редактором.
- `server.mjs`: локальный сервер и запрос к OpenAI Responses API.
- `template.b64.txt`: корпоративный шаблон резюме (.docx в кодировке base64), из него берутся оформление, шрифты Montserrat и логотипы.
- `lib/jszip.min.js`: работа с .docx (JSZip).
- `lib/pdf.min.mjs`, `lib/pdf.worker.min.mjs`: чтение PDF (pdf.js).

## Проверка

`node --test` проверяет поток отправки с имитацией ответа OpenAI, обработку ошибок и скрытие контактов. Для пробного запроса к OpenAI используйте вымышленное резюме.

## Ограничения

- Не читаются сканы без текстового слоя, файлы Word 6/95 и файлы с паролем.
- Разбор по правилам не переформулирует текст: формулировки навыков «Тестирование» собираются по ключевым словам резюме, остальное переносится как есть.
- Сверяйте разбор ИИ с исходным файлом. Перед отправкой доступны до 45 000 символов резюме и до 12 000 символов вакансии.
- PDF рисуется отдельно по тому же макету, что и .docx: ручные правки .docx в Word в него не попадают.
