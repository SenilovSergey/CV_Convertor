# Конвертер резюме QA

## Версия для ChatGPT Work

Ветка `chatgpt-work` содержит инструкции и экспорт для личного сценария «Корпоративное резюме». В ChatGPT Work приложите резюме и попросите адаптировать его к корпоративному шаблону. После проверки черновика попросите сформировать DOCX или PDF. Эта версия использует модель текущего чата и работает без API-ключа.

- [Инструкции и структура черновика](work/SKILL.md)
- [Сборка DOCX и PDF](work/scripts/resume.py)

Для подготовки чистого шаблона и проверки сборки из репозитория выполните:

```bash
mkdir -p work/assets
python3 work/scripts/resume.py prepare-template template.b64.txt work/assets/corporate-cv.docx
```

Экспорт использует Python и `lxml`. Для фото нужны `python-docx` и Pillow. Чтение PDF использует `pdftotext`, а чтение DOC/RTF и экспорт PDF — LibreOffice.

## Веб-конвертер

Веб-приложение переносит резюме кандидата (.docx, .doc, .rtf или .pdf) в корпоративный шаблон и выдаёт готовый файл .docx или .pdf.

Всё работает в браузере, без нейросетей и внешних сервисов: файл резюме никуда не отправляется, ключи и регистрация не нужны.

## Как пользоваться

1. Загрузите резюме. Оно сразу разбирается по правилам: ФИО и контакты, должность, стаж, места работы (период, компания и проект, должность, обязанности, достижения, стек), навыки, образование, курсы, языки.
2. Выберите вид шапки (полная или «Имя Ф.»), при необходимости поправьте ФИО, контакты и фото.
3. Проверьте и поправьте поля в блоке «Проверка и правка»: всё, что там написано, попадёт в файл.
4. Если нужно, вставьте требования вакансии и нажмите «Применить к резюме»: совпадающие навыки и обязанности поднимутся наверх, а в заметках появится список того, чего из вакансии нет в резюме. Текст резюме при этом не меняется.
5. Нажмите «Сформировать .DOCX» или «Сформировать .PDF».

Имя файла: фамилия кандидата для полной шапки, «Имя Ф.» для сокращённой.

Разбор лучше всего работает с выгрузками hh.ru, Хабр Карьеры и внутренними резюме ЛАНИТ; резюме свободной формы может потребовать больше ручных правок.

## Публикация на GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save. Сайт откроется по адресу `https://<логин>.github.io/<имя-репозитория>/` (для этого репозитория: https://senilovsergey.github.io/CV_Convertor/).

## Состав

- `index.html`: приложение (разметка, стили, разбор резюме, редактор, сборка .docx и .pdf) в одном файле.
- `template.b64.txt`: корпоративный шаблон резюме (.docx в кодировке base64), из него берутся оформление, шрифты Montserrat и логотипы.
- `lib/jszip.min.js`: работа с .docx (JSZip).
- `lib/pdf.min.mjs`, `lib/pdf.worker.min.mjs`: чтение PDF (pdf.js).

## Ограничения

- Не читаются сканы без текстового слоя, файлы Word 6/95 и файлы с паролем.
- Разбор по правилам не переформулирует текст: формулировки навыков «Тестирование» собираются по ключевым словам резюме, остальное переносится как есть.
- PDF рисуется отдельно по тому же макету, что и .docx: ручные правки .docx в Word в него не попадают.
